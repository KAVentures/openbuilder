# GitHub repository presentation (maintainers)

The repository's root [README](../README.md) is rendered automatically on its GitHub first page, and GitHub detects the existing [MIT LICENSE](../LICENSE).

Some **About** sidebar metadata is stored in GitHub repository settings, not in Markdown files. If your GitHub connector doesn't offer repository-metadata changes, set these once on [the repository homepage](https://github.com/KAVentures/openbuilder):

1. On the right side, locate **About** and click its **gear icon**.
2. Paste the description and topics below, then **Save changes**.
3. Leave **Website** empty until there is an actual product website. Do **not** enter a Vercel deployment URL that doesn't exist.
4. Verify GitHub displays **MIT** as the license, and the latest CI badge is green.

**Suggested description (copy verbatim):**

> Build and ship web apps and browser games with the AI you already use. Open-source workflows, local previews, security checks and guided deployment.

**Suggested topics** (lowercase, separated when entering in GitHub's topic picker):

`open-source` · `ai-app-builder` · `coding-agent` · `agent-skills` · `chatgpt` · `claude-code` · `codex` · `nextjs` · `supabase` · `vercel`

**Social preview:** optional. Add a real image via **Settings → General → Social preview** when an approved project graphic exists; GitHub does not automatically turn README Markdown into a custom share image.

**About statement:** this repository is an independent open-source toolkit, **not** officially affiliated with AI/model or infrastructure providers.
