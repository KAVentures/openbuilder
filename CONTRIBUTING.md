# Contributing

Thanks for contributing! OpenBuilder is MIT licensed and welcomes focused improvements.

1. Open an issue describing the problem or proposed change.
2. Fork or branch from main; avoid unrelated refactors.
3. Use Node.js 20+, run `npm test` and `npm run check`.
4. Add or update tests for CLI behavior, security checks and retry limits.
5. No secrets, personal data, credential fixtures, or real API tokens in commits/issues/screenshots.
6. Submit a pull request explaining the behavior and exactly which checks you ran.

Avoid implying automated proof of security, SEO ranking, legal compliance or email deliverability where only static checks exist.
